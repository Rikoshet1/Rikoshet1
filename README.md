## 🚀 Featured projects

### 📖 [CodeStory](https://github.com/Rikoshet1/CodeStory)
**A VS Code extension that explains *why* a line of code exists.**
Select code and CodeStory traces it through **git history**, **GitLab Merge Requests**, and **Jira tickets**, then uses an LLM to stream a clear, source-backed explanation. It includes an `@codestory` chat participant for follow-up questions.

- 🏆 Finalist in a company-wide AI Hackathon
- 🔌 Acts as a **Model Context Protocol (MCP)** client to fetch Jira context
- 🤖 Works with any OpenAI-compatible model; streaming responses in a custom Webview
- 🔐 Secrets stored in the OS keychain
- 🧱 Contract-first architecture, tested with Mocha and linted with ESLint

`JavaScript` · `VS Code API` · `MCP` · `GitLab API` · `Jira` · `LLMs`

### ✨ [InspireWall](https://github.com/Rikoshet1/InspireWall)
**A personal space for quotes and thoughts worth keeping.**
A full-stack app where you save inspiration items and let **Gemini** suggest meaningful Hebrew tags, then browse and search your collection in a calm, responsive board.

- ⚛️ React + Vite frontend with search, tag filtering, and offline sample data
- ☕ Spring Boot REST API with MongoDB persistence
- 🧠 AI-generated Hebrew tags via the Gemini API (keys kept server-side)
- 🛣️ Roadmap: DTOs and validation, semantic search with embeddings, async AI tasks, authentication

`React` · `Java` · `Spring Boot` · `MongoDB` · `Gemini API`
